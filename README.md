# DRAGONSLEEP

An 8-bit, turn-based RPG of Silverton and the Silverton–Pit corridor, in the shape of the old console RPGs, with 5E-flavored rules. Pick one of four heroes, hire the other three, make a name in town, and go down the road to the thing in the lake.

**Play:** https://grimgriz.github.io/dragonsleep-8bit/ — works in any modern browser, on a phone too (touch d-pad). You can also open `index.html` straight from disk.

**Controls:** arrows or WASD to walk · E (or Z / Enter / Space) to talk and choose · X / Esc to open the menu and go back.

**Up to the Doors, down to the Pit:** coming in an expansion pack. [Donate to support it](https://ko-fi.com/grimgriz).

## What's in it

- **Silverton** — Fountain Street, the Weigh-House bounty board, the Hex and its fight card, vice row, the Shaft Rows, shops, the mission chapel, the leech-house, Winters' Acquisitions & Estates.
- **The Crawler Warrens** — the mouth camp, the pens and the lit galleries, the abandoned workings, and the wet: Pete's five.
- **The guano mine** — the mouth, the working gallery, the dens and the cull, the deep gallery and the forty-gold tail.
- **Web Gulch**, the **Glowseep**, the **Gnoll Hills**, the **Verge** and the road south.
- **The Halfway Inn and Halfway Lake** — the capstone.
- Four heroes (Barley, Aurdin, Vivian, Lymen "Ly" Urtusk), levels 2–5; Fighter, Wizard, Rogue and Paladin features from the SRD 5.1.

## How it's built

Plain HTML, canvas and classic scripts; no build step to play. All pixel art, tiles, the font and the chiptune music are generated in code (`js/art.js`, `js/sprites.js`, `js/bestiary-art.js`, `js/font.js`, `js/audio.js`). Nothing is copied from any other game.

One scene steps outside the 8-bit frame on purpose: a shift at the Warrens' cradles (`js/cradle.js`) is drawn at full resolution on a second canvas laid over the game screen, with the lamp, the timber, the animal and your hands drawn from curves and light, then taken away again when the shift ends.

The content comes from the TarlynsPit register (the wiki and the module packages). It is hand-authored as JSON in `content/`, where every record cites its source page (`"src"`), then compiled:

```
python tools/mapgen.py      # lay out every map -> content/maps/*.json
python tools/compile.py     # validate + bundle content/ -> data/data.js
python tools/checkmaps.py   # every door, warp, NPC and chest reachable
```

`compile.py` refuses to build if a record has no source, a map points at a missing map, an NPC has no dialogue, or a script uses a missing line. Set `DS_REGISTER` to the TarlynsPit folder to also check that every cited page exists.

| folder | what |
|---|---|
| `js/` | engine: core loop and input, font, art, sprites, monsters, audio, rules, battle, field, menus, events |
| `content/` | the source data: heroes, items, spells, monsters, encounters, shops, NPC dialogue, story text, rumors, quests, config |
| `content/maps/` | generated by `tools/mapgen.py` |
| `data/` | compiled bundle (`data.js` loads from `file://`) |
| `invented.json` | everything the build made up, one line each, **PROPOSED** — never written back to the wiki |

## Canon discipline

The game stands on the register, but it is its own telling. Where the register holds something open or reserved (Winters' own words, what is in Hessle's drawer, the inn's fate, Mama's), the build drafts it and the draft stands. There are no `[GRIZ]` stubs in play (Griz, 2026-09-24), and the wiki is not edited to match the game. Every drafted or invented thing is logged in `invented.json`.
