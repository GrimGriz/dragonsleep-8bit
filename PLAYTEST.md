# DRAGONSLEEP — playtest checklist

Live: https://grimgriz.github.io/dragonsleep-8bit/ · Z/Enter = use · X/Esc = menu/back · arrows/WASD = walk

Tested so far only by bots (49 battles, every scripted scene) and a map-reachability checker. **Nobody has played it start to finish.** Mark anything that feels wrong, too hard, too easy, or unclear.

## 1. Start and town
- [ ] Title → New Game → try each of the four leads once (intro text reads right for each?)
- [ ] Silverton: walk every street; doors open shops/keepers when you walk in; you're stepped back out after
- [ ] Weigh-House (Hessle) reads the bounty board; the vault door sign; vice row booths
- [ ] Shops: buy/sell, equip-now prompt, ▲▼ markers make sense; the silver economy feels fair
- [ ] Inn (Cassia, 8 sp each) and Aldwin's free chapel floor both rest + offer save
- [ ] Leech-house revives KO'd heroes for 5 sp each
- [ ] Field menu: ITEM / MAGIC / SKILL / EQUIP / STATUS / ORDER / JOURNAL / SAVE / OPTIONS all work
- [ ] Save to a slot, quit to title, CONTINUE loads it back correctly
